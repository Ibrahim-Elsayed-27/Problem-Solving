# Problem Solving – LeetCode Solutions

This repository contains a curated collection of **LeetCode problem solutions** that I solved while practicing data structures and algorithms.  
Most solutions are written in **C++**, with some problems solved using **SQL** and **Java**.

This is not a complete archive of all problems I’ve attempted. Instead, it reflects problems that helped me **understand and recognize common problem-solving patterns**.

---

## Why this repository exists

This work was done during a **7-week Data Structures & Algorithms problem-solving course** as part of my **9-month ITI Cloud Platform Development program**.

Throughout the course, one key idea was repeatedly emphasized:

> **Problem solving is a pattern-recognition skill.**

This repository represents my first structured step toward building that skill—by struggling with problems, recognizing patterns, and gradually improving my approach.

---

## Repository structure

```

LeetCode/
├── Easy/
├── Medium/
├── Hard/
│
└── Each problem has:
├── A solution file (C++ / SQL / Java)
└── A README.md with a brief explanation

```

Problems are organized by **difficulty**, and each problem lives in its own directory for clarity and focus.

---

## Topics explored

The problems here touch on a variety of core topics, including:

- Arrays & Strings
- Hash Tables
- Recursion & Backtracking
- Trees & Binary Search Trees
- Graphs (DFS, BFS, Topological Sort)
- Dynamic Programming
- Greedy Algorithms
- Sorting & Searching
- SQL Queries (Filtering, Aggregation, Joins)

These topics were not studied in isolation, but as recurring patterns that appear across different problems.
